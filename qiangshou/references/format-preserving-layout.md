# 内容冻结排版

## 1. 何时冻结

用户说“终稿”“发布版”“最终文案”“不要改内容”“只加小标题”“只调整排版”“保留原话”或“不要润色”时，冻结当前正文。不要因为发现更好的写法而切换到重写模式。

终稿保护优先于排版便利：除用户明确授权外，只能建议，不能直接修改文字或顺序。用户删除或否决的内容不得重新加入或反复建议。

## 2. 确认底稿

按以下顺序选择：

1. 用户本轮明确指定的文件或文本。
2. 用户明确称为“我手动修改的稿”的版本。
3. 有证据显示由用户最近编辑的版本。
4. 仍有歧义时，列出候选文件的路径、修改时间和开头内容，请用户确认。

用户指定的文件优先于名称含“终稿”“最新版”“优化版”的生成稿；不要只凭文件名猜最新版，不覆盖用户源文件。

## 3. 允许与禁止

### 允许

- 添加或调整标题层级
- 添加不包含新事实的小标题
- 添加粗体、斜体、引用、代码块、空行与分隔线
- 把用户已有数据改成数据卡或表格，但不改变含义
- 插入图片、图注与图片替换位
- 拆分或合并纯版式段落，但保持字符顺序
- 修正用户明确授权的错别字

### 禁止

- 同义改写、删重、扩写或概括
- 添加连接句、总结句、金句或新论点
- 调整段落、案例或章节顺序
- 改变数字、时间、归因、范围与观点
- 把约数改成精确数字，把反馈改成普遍结论
- 恢复用户已经删除或否决的内容

小标题属于导航文字，可以概括下方内容，但不能制造正文没有的结果、冲突或判断。

## 4. 错别字

只有用户明确允许时，才修正明显错字、漏字、重复字和标点错误，并记录“原文 → 修正”。不要借“改错字”替换语气、句式、术语或观点；有疑义时只建议。

## 5. 可选内容保持验证

仅当用户明确要求“内容完全不变并验证”时运行：

```bash
python scripts/verify_content_preservation.py <原文或确认基线.md> <排版稿.md>
```

若失败，先恢复被改文字；只有经用户授权的错字修正可以同步进基线并记录。该脚本验证正文字符以及原有标题未被改写、删除或调序；允许新增导航小标题，但不验证新增小标题质量、图片事实或排版审美。

不把摘要、SHA、基线复制或逐次校验设为默认流程。交付时说明使用的底稿、排版新增项和错字记录；若用户要求验证，再附结果。
